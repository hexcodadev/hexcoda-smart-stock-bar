Add a lightweight stock progress bar to WooCommerce product pages.

== Description ==

HexCoda Smart Stock Bar for WooCommerce helps store owners show available product stock with a simple, focused progress bar.

The plugin is built to do one job cleanly: display a stock bar when WooCommerce inventory is managed for a product.

= Features =

* Show a stock progress bar on product pages
* Low, medium, and high stock states
* Configurable maximum stock cap
* Custom labels for each stock state
* Choose where the bar appears on the product page
* Customize low, medium, high, and background colors
* Customize font size, bar height, and spacing
* Optionally hide WooCommerce variation availability text
* Lightweight frontend CSS
* No tracking and no external services

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/hexcoda-smart-stock-bar` directory, or install the plugin through the WordPress plugins screen.
2. Activate the plugin through the Plugins screen in WordPress.
3. Go to WooCommerce > HexCoda Stock Bar to configure the plugin.
4. Make sure stock management is enabled on the products where you want the bar to appear.

== Frequently Asked Questions ==

= Does this plugin require WooCommerce? =

Yes. WooCommerce must be installed and active.

= Does the plugin create fake stock? =

No. The free plugin uses the product stock quantity managed by WooCommerce.

= Does this plugin send data to HexCoda? =

No. This plugin does not track users or send data to external services.
