# Contributing

Thanks for helping improve HexCoda Smart Stock Bar for WooCommerce.

## Development Standards

- Keep the plugin focused on one job: a lightweight WooCommerce stock bar.
- Follow WordPress coding standards.
- Sanitize all saved input.
- Escape all output.
- Check capabilities before admin-only actions.
- Keep frontend assets lightweight.
- Avoid external services unless they are clearly disclosed and optional.

## Pull Requests

Before opening a pull request:

- Run PHP syntax checks.
- Test with WooCommerce active.
- Test a product with managed stock.
- Update `readme.txt` or documentation when behavior changes.
